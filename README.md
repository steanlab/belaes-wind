# belaes-wind

Интерактивная учебная карта: куда могло бы пойти облако выброса БелАЭС при текущем ветре.

Страница: https://steanlab.github.io/belaes-wind/

**Это учебная иллюстрация, а не прогноз и не инструмент оценки риска.**

© [Сергей Бесараб](https://t.me/lab66) ([LAB-66](https://t.me/lab66)) 2025

## Возможности

- Облако растет на карте, рядом идут часы модельного времени, есть пауза и скорость ×0,5, ×1, ×2, ×4.
- Карта сама отдаляется, когда облако подходит к краю экрана.
- Режим «А если ветер другой?»: свое направление и скорость ветра.
- Сводка «Накрыто городов», список из 29 городов (сначала накрытые, по времени прибытия), клик по городу центрирует карту на нем.
- Четыре языка: русский, белорусский, английский, польский. Язык берется из `?lang=`, потом из сохраненного выбора, потом из языка браузера.
- «Поделиться»: ссылка (с параметрами ветра, если он свой) или системное окно «Поделиться».
- «Сохранить картинку»: PNG 1200×630 с итогом симуляции (без подложки карты).
- Установка как приложение (PWA): работает на телефоне и компьютере, запускается и без сети (карта и ветер без сети недоступны).
- Объявления для программ чтения с экрана о том, когда облако достигло города.

## Параметры ссылки

| Параметр | Значение |
|---|---|
| `lang` | `ru`, `be`, `en` или `pl` |
| `wd` | откуда дует ветер, градусы от 0 до 360 |
| `ws` | скорость ветра, м/с, от 0,5 до 25 |
| `run` | `1`: сразу запустить (только вместе с `wd` и `ws`) |

Пример: `https://steanlab.github.io/belaes-wind/?lang=be&wd=270&ws=6&run=1`

## Откуда данные

[Open-Meteo](https://open-meteo.com/) (`wind_speed_10m` и `wind_direction_10m`, скорость в м/с). Это модельные значения на высоте 10 м, а не измерения на станции. Ключ API не нужен. Open-Meteo без ключа предназначен для некоммерческого использования, условия: https://open-meteo.com/en/features#terms. Данные распространяются с обязательным указанием источника (CC BY 4.0), оно есть в боковой панели и в окне «О модели».

Направление ветра в Open-Meteo метеорологическое, то есть **откуда** дует ветер. Облако движется в противоположную сторону: азимут переноса равен `направление + 180°`.

## Модель

1. Ветер берется один раз в момент запуска и **не меняется** до конца симуляции. Обновления ветра каждые 5 минут влияют только на данные в панели до следующего запуска.
2. Ось облака идет по дуге большого круга в сторону переноса со скоростью ветра.
3. Облако это конус с полууглом 15° (`PLUME_HALF_ANGLE_DEG`), его ширина растет линейно с расстоянием.
4. «Коридор неопределенности» это два таких же конуса, ось которых повернута на ±15° (`AXIS_UNCERTAINTY_DEG`). Крайняя граница коридора поэтому лежит на 30° от оси. Оба значения условные и не выведены из статистики ошибок прогноза ветра.
5. Город считается накрытым, когда он попадает внутрь центрального конуса. Время прибытия равно расстоянию по дуге большого круга, деленному на скорость ветра.
6. Через 48 модельных часов симуляция останавливается.
7. Прозрачность облака уменьшается со временем. Это условный прием, он не передает реальное падение концентрации (оно на порядки).

## Чего в модели нет

Высоты выброса и ветра на высоте облака, вертикального сдвига и поворота ветра с высотой, изменения погоды за двое суток, турбулентной диффузии (классы устойчивости), сухого и влажного осаждения, радиоактивного распада, источника (нуклид, активность, длительность выброса), рельефа. Для настоящих оценок используются траекторные и дисперсионные модели (например, HYSPLIT, FLEXPART) и системы поддержки решений при авариях (например, RODOS).

## Что еще важно

- Выбор городов в списке `CITIES` не имеет формального критерия, это иллюстративный набор. Названия городов на четырех языках заданы в самом списке.
- Рекомендации по йоду на странице даны справочно. Доза и показания зависят от возраста и здоровья, решение о профилактике принимают власти. Первичный источник: [руководство ВОЗ 2017](https://www.who.int/publications/i/item/9789241550185).
- Страница не собирает данные о посетителях, но браузер обращается к Open-Meteo, OpenStreetMap и unpkg, и эти сервисы видят IP-адрес.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | страница, мета-теги, структурированные данные |
| `script.js` | модель, карта, интерфейс, работа с Open-Meteo |
| `i18n.js` | тексты на четырех языках |
| `style.css` | оформление |
| `manifest.webmanifest`, `sw.js` | установка как приложение и работа без сети |
| `icons/` | значки приложения (`icon.svg`, PNG разных размеров) |
| `wind-rose-base.svg`, `wind-rose-pointer.svg` | роза ветров |
| `preview-image.jpg` | картинка для соцсетей |

Функции геометрии и форматирования в `script.js` не зависят от DOM и Leaflet и экспортируются через `module.exports`, чтобы их можно было проверить в Node.

## Для разработчика

- Новая версия: поменяйте `APP_VERSION` в `script.js` и `VERSION` в `sw.js`, чтобы устаревший кэш приложения был очищен.
- Добавить язык: добавьте блок в `STRINGS` и запись в `LANGS` (`i18n.js`), названия городов в `CITIES` (`script.js`) и пункт в `<select id="langSelect">` (`index.html`). В строках сайта не используйте точки с запятой и длинные тире.
